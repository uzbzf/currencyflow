# CurrencyFlow

Современный конвертер валют и криптовалют на **React + Vite + Tailwind CSS**.

## Возможности

- Конвертация: USD, EUR, CNY, RUB, UZS, KZT, BTC, ETH
- Живые курсы (ExchangeRate-API, CoinGecko) + резервные курсы
- Комиссия, история, QR-шаринг, чек PNG, график за 7 дней
- Светлая / тёмная тема, поиск по валютам, калькулятор выражений

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```
